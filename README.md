# CousCous - Leitor de Feeds RSS

Um leitor de feeds RSS/Atom com interface web/desktop construído com Flet e API FastAPI.

## Funcionalidades

- Multiusuário, com registro e autenticação OAuth (Google, Github)
- Organização de inscrições (feeds) em categorias hierárquicas (pastas)
- Sistema de etiquetas para marcar notícias (favoritos, importante, etc)
- Busca no conteúdo das notícias
- Visualização alternativa por categorias e etiquetas
- Temas claro/escuro personalizáveis
- Limpeza do banco de dados (apagar notícias mais antigas)
- Backup e restauração dos dados com criptografia
- Copiar link de notícia para compartilhamento
- Ajuste do tamanho do texto conforme necessidades do usuário
